Results

Real numbers from Hoverfly's own test sets, measured against the on-device alternatives — not marketing copy.

On hand-written chat messages, Beacon detects the right language 88.3% of the time — versus 71.3% for Google ML Kit Language ID on the same set.

Learn more ↗

98.8% of everyday chat messages pass through Gatekeeper clean — few false alarms, even on slang and mixed-script text.

Learn more ↗

Comeback's top 3 reply chips include a good one 63.6% of the time, in 4.6 MB — versus 6.6 MB plus native libraries for Google ML Kit Smart Reply.

Learn more ↗

On fresh hand-written Indian chat messages, Hideout hides 96% of phone numbers, UPI IDs, Aadhaar, PAN and other personal details — versus 64% for Microsoft Presidio — in 8 MB.

Learn more ↗

Chalk names a doodle right on the first guess 81% of the time across 345 things, and in the top 3 94% — in 1.8 MB, 200× smaller than a BEiT image model that scores 83%.

Learn more ↗

On Hinglish chat, Comma places punctuation with an F1 of 0.83 — versus 0.49 for a 1.1 GB XLM-R punctuation model — in 7.8 MB.
